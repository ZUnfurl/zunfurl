# A 方案客户手册：静态品牌官网

适用范围：纯品牌官网。网站用于品牌展示、基础信息发布和联系入口，不提供交易功能，也不需要客户登录内容后台。

仓库和平台仍按统一完全交付规则归客户所有。A1/A2 没有内容 CMS，不代表代码、域名或 Cloudflare 长期属于维护方；A2 启用的 Resend、Turnstile 也必须是客户专属资产，协调对象随客户 Worker 部署。日常内容更新由维护方按合同执行，平台资产登记表另行交给客户授权管理员。

## 你需要做什么

A 方案由维护方托管内容更新。你只需要整理修改需求，并交给维护方处理。

常见需求包括：

- 修改首页、关于页或联系页文案。
- 更换品牌图片或视频。
- 修改联系方式、地址、合作说明。
- 更新法律页、隐私说明或服务说明。
- 临时关闭或替换某个展示区块。

## 修改内容时怎么提交

建议一次提交清楚以下信息：

1. 要修改的页面，例如 Home、About、Contact。
2. 要修改的语言，例如 English、Français、简体中文。
3. 原文位置或截图。
4. 新文案或新图片。
5. 期望发布时间。

如果是图片，请同时提供图片用途，例如首页首屏、About 图文介绍、Contact 背景图。维护方会检查尺寸、压缩、格式和移动端显示效果。

## Contact 表单

A 方案默认不启用真实表单接口。联系入口可以使用：

- 邮箱链接。
- 外部表单链接。
- 简单联系说明。

如果你需要“用户提交表单后自动发邮件”，这属于 A2 轻量表单能力，需要额外启用表单接口、防滥用验证和邮件服务。

## 发布与验收

维护方完成修改后，会提供预览或正式网址供你检查。

验收时重点看：

- 文案是否正确。
- 图片是否清晰、裁切是否合适。
- 手机端是否容易阅读。
- 导航和按钮是否能打开正确页面。
- 联系入口是否能正常使用。

## 不需要你操作的内容

A 方案客户不需要操作：

- Sanity Studio。
- Shopify 后台。
- GitHub Actions。
- Cloudflare。
- 命令行、npm、部署脚本。
- token、secret 或 webhook。

## 什么时候联系维护方

以下情况直接联系维护方：

- 需要修改页面内容或图片。
- 页面显示异常、图片丢失或按钮打不开。
- 联系入口失效。
- 多语言内容需要同步。
- 需要临时活动页、公告页或新页面。
