# C 零售目录与内容运营基础框架客户手册

英文名称：**C Retail Catalog & Content Foundation**。机器 profile 仍为 `retail`。

适用范围：品牌官网 + 内容 CMS + 商品内容 CMS + Shopify 只读目录映射。你需要同时使用 Sanity Studio 和 Shopify，但不需要操作 GitHub、Cloudflare、命令行或部署脚本。

本框架不包含 Cart、Checkout、支付、订单、税务、配送、履约、实时价格或实时库存，也不承诺用户可以在站内完成购买。

正式代码仓库、域名、Cloudflare、Sanity 和 Shopify 均按统一完全交付规则归客户所有；启用 Contact 时，Resend、Turnstile 也属于客户，协调对象随客户 Worker 部署。客户授权管理员另行保管平台资产登记表、账户恢复方式、账单和凭据轮换信息，内容编辑与商品管理员日常只使用本手册中的 Studio 和 Shopify 入口。

## 你会使用哪些入口

Sanity Studio：

- 页面工作台：维护 Home、About、Products、Contact 等固定页面。
- 商品上线向导：把 Shopify 目录项接入网站商品内容。
- 商品工作台：维护商品语言页、上下线、归档、取消归档和 Shopify 只读目录映射同步。
- 全部内容：高级兜底入口，普通编辑优先不用。

Shopify：

- 创建供目录映射使用的商品记录。
- 维护商品身份、handle、媒体和受支持的目录结构。
- 通过 Headless channel 向本框架提供只读目录事实。

## 内容和目录边界

Sanity 管内容：

- 页面文案、图片、SEO。
- 商品卡片文案。
- 商品详情页内容。
- 商品故事页。
- 各语言是否上线。
- 商品内容归档和取消归档。

Shopify 提供只读目录事实：

- 商品是否存在。
- 商品名、handle、商品图片。
- 受支持的目录结构摘要。

价格、库存、SKU、订单、支付或履约状态不得写入 Sanity 或静态内容。即使 Shopify 中存在这些数据，本框架也不把它们作为已交付的实时前台能力。

## 修改页面内容

页面内容使用页面工作台。详细操作见：

- [页面运营手册](customer-page-operations.md)

一般流程：

1. 进入页面工作台。
2. 选择页面和语言。
3. 修改模块内容。
4. Publish。
5. 等自动构建完成后预览。

## 发布一个新的商品目录内容

1. 先在 Shopify 创建供目录映射使用的商品记录。
2. 确认商品名、handle、图片和受支持的目录结构正确。
3. 将商品发布到 Headless channel，供 Storefront API 只读读取。
4. 打开 Sanity Studio。
5. 进入商品上线向导。
6. 刷新 Shopify 商品列表。
7. 选择要上线的商品。
8. 选择要创建或发布的语言。
9. 选择复制模板。
10. 创建或补齐商品内容。
11. 回到商品工作台，编辑对应语言页面。
12. 确认无误后 Publish。
13. 等自动构建完成后检查前台页面。

如果只想先上线英文，只发布 English。Français 和简体中文可以保留为草稿或就绪，不需要删除。

## Shopify 目录信息变更

如果在 Shopify 修改了商品名、handle、图片或变体摘要：

1. 先在 Shopify 完成修改。
2. 回到 Sanity Studio。
3. 打开商品工作台。
4. 找到对应商品。
5. 如果提示映射需同步，点击同步 Shopify 映射。
6. 如果前台文案也要变化，再进入对应语言页手动修改标题、SEO 或正文。

同步 Shopify 映射不会覆盖 Sanity 中的正文、故事、SEO 或语言上线状态。

## 商品内容下线、归档和取消归档

日常优先使用商品工作台：

- 暂时隐藏某种语言：使用下线语言。
- 重新启用某种语言：回到草稿状态，检查后再上线。
- 整个商品废弃：使用归档整个商品。
- 商品内容重新启用：在已归档视图中取消归档。

归档和取消归档只改变 Sanity 商品内容是否进入日常运营和前台构建；它们不是 Backup 或 Restore，也不会创建恢复点。

普通运营不要直接删除语言页面。整档删除属于管理员危险区，只用于确认废弃或错误创建的整组商品内容。

详细规则见：

- [商品运营手册](customer-product-operations.md)

## Contact 表单和范围提示

Contact 表单由网站系统处理。你可以在 Contact 页面中维护联系说明和提交前法律提示。

网站正式上线前，应检查：

- 隐私政策。
- 使用条款。
- 客户服务与联系说明。

法律文档模板在 `docs/legal/` 中，正式发布前仍建议由律师按适用地区和真实业务流程复核。如果未来接入外部交易系统，销售、税务、配送、退货与退款责任需要在该系统的独立项目中另行设计和审查。

## 什么时候联系技术维护人员

以下情况联系技术维护人员：

- 商品上线向导找不到 Shopify 商品。
- 商品工作台显示 Shopify 不可读取。
- 点击同步 Shopify 映射后仍显示需要同步。
- Publish 成功后前台长期不更新。
- GitHub Actions 或 Cloudflare 部署失败。
- 多个商品、多个页面或多个语言同时异常。
- 误删内容；Studio 回收站只提供尽力还原，不是生产备份且不构成恢复保证，应立即停止继续编辑并升级处理。
- 需要批量导入、批量删除或大规模迁移。

普通页面修改、单个语言发布、商品文案修改、商品归档和取消归档，运营人员可以自行完成。
