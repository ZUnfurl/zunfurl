# B 方案客户手册：可自维护品牌官网

适用范围：品牌官网 + 内容 CMS。你可以通过 Sanity Studio 自己维护页面内容，但网站不提供交易功能，不启用 Shopify，也不启用商品工作台。

正式代码仓库、域名、Cloudflare 和 Sanity 均按统一完全交付规则归客户所有；启用 Contact 时，Resend、Turnstile 也属于客户，协调对象随客户 Worker 部署。客户授权管理员另行保管平台资产登记表、账户恢复方式、账单和凭据轮换信息，内容编辑日常只使用本手册中的 Studio 入口。

## 你会使用哪些入口

日常只使用 Sanity Studio：

- 页面工作台：维护固定页面内容。
- 全部内容：高级兜底入口，普通编辑优先不用。
- Vision / Releases：保留给技术维护或未来批量发布使用，日常可以不打开。

B 方案不会显示：

- 商品工作台。
- 商品上线向导。
- 商品语言页面。
- Shopify 映射同步。

## 当前可维护页面

当前默认 B 方案维护以下页面：

- Home。
- About。
- Contact。

Products 和商品详情页默认不启用，因为 B 方案不连接 Shopify，也不维护商品 CMS。未来如果需要商品目录、商品故事和多语言商品内容运营，应明确升级到 C 零售目录与内容运营基础框架；单纯的品牌系列介绍仍可作为 B 的独立内容模块评估。

## 修改一个页面

1. 打开 Sanity Studio。
2. 进入页面工作台。
3. 选择要修改的页面。
4. 选择要修改的语言。
5. 点击编辑页面。
6. 按编号修改对应模块。
7. 点击 Publish。
8. 等待自动构建完成后，点击查看已发布页面检查效果。该入口打开已发布前台，不是 Sanity 草稿预览。

只修改某一种语言，不会影响其他语言。

## 图片怎么维护

B 方案优先使用 Sanity Image CDN：

- 内容编辑可以在 Studio 中上传或选择页面图片。
- 本地图片路径只作为管理员 fallback，不是日常编辑入口。
- 如果图片显示异常，先检查对应页面的图片来源和图片说明。

不要把本地图片路径当成日常素材库；它主要用于迁移、兜底和技术维护。

## Contact 页

如果启用了轻量表单，Contact 页可以通过 Studio 维护：

- 表单是否显示。
- 左侧联系说明。
- 自定义说明。
- 提交前法律提示。
- SEO。

表单字段、咨询类型、提交按钮和提交状态反馈通常由系统固定，普通编辑不需要修改。

如果没有启用轻量表单，Contact 页只作为联系说明页面，不提供真实提交接口。

## 发布后没有变化怎么办

先等待几分钟。发布后系统需要重新构建网页。

如果仍没有变化：

1. 检查对应语言页面是否真的 Publish。
2. 检查是否改错语言。
3. 回到页面工作台查看是否仍显示草稿。
4. 仍异常时联系技术维护人员。

## 不要自己处理的事情

以下情况联系技术维护人员：

- 页面工作台显示缺文档。
- 页面出现黄色 Unknown fields 提示。
- 多个页面或多个语言同时异常。
- Contact 表单无法提交或长期收不到邮件。
- 需要新增固定页面。
- 需要批量导入、批量翻译、批量删除或处理误删内容。

B 方案客户不需要接触 Shopify、价格、库存、SKU、订单、支付、配送或商品上下线流程。
